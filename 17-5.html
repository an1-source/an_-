⏱ JavaScript 定时器

setTimeout — 单次延迟执行  |  setInterval — 周期性循环执行

① setTimeout — 延迟执行一次

示例 1：延迟 3 秒后显示消息 clearTimeout 可取消

点击启动后会创建一个 3 秒定时器，3 秒后输出"到点了！"。期间点"取消"可阻止执行。

const timerId = setTimeout(() => {
    console.log("3 秒到点了！");
}, 3000);

// 若想取消：
clearTimeout(timerId);
（等待启动）

② setInterval — 周期循环执行

示例 3：实时时钟

每秒执行一次，刷新时分秒。

setInterval(() => {
    document.title = new Date().toLocaleTimeString();
}, 1000);

③ 定时器清理原理说明

⚠️ 一定要保存 ID 才能取消

// setTimeout / setInterval 都返回一个数字 ID
const t = setTimeout(fn, 1000);
const i = setInterval(fn, 1000);

// 取消必须用对应 ID
clearTimeout(t);
clearInterval(i);

// 用完记得清理，否则：
// - setInterval 会一直跑，哪怕页面切到后台
// - 组件销毁/页面关闭前必须 clear，防止内存泄漏
