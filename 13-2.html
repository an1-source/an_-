Lucide SVG 图标

13-2 · 安家成 · SVG 图标（内联 svg + currentColor）

一、引入方式与图标原理

Lucide 的每个图标都是一段 SVG 矢量图形。把库文件下载到本地后， 页面里写 <i data-lucide="house"></i>， 调用 lucide.createIcons() 会把它替换成真正的内联 <svg> 节点——不是字体，也不是图片文件。 

<script src="cdn/lucide/lucide.min.js"></script>
<i data-lucide="house"></i>          <!-- 占位符 -->
<script>lucide.createIcons();</script>  <!-- 替换成内联 <svg> -->

/* 渲染结果（SVG 源码片段） */
<svg class="lucide lucide-house" xmlns="http://www.w3.org/2000/svg"
     width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 0 0 0-1 1v8"/>
  <path d="M3 10a2 2 0 0 1 .709-1.528l7-6a2 2 0 0 1 2.582 0l7 6A2 2 0 0 1 21 10v9a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/>
</svg>
关键点：stroke="currentColor" 让描边颜色等于当前文字 color， 所以图标会跟随文字变色；width / height 控制尺寸（任意缩放不失真）； stroke-width 控制线条粗细；viewBox="0 0 24 24" 是图标的设计坐标系。 渲染后元素上会带 class="lucide lucide-house"，方便用 CSS 选中。

三、尺寸、描边与颜色（SVG 属性可控）

拖动滑块会实时修改 SVG 的 width / height / stroke-width 属性， 点色块修改的是外层的 color——因为描边是 stroke="currentColor"，SVG 会自动跟着变色。

颜色：

代码里的写法：<svg width="32" height="32" stroke-width="2" stroke="currentColor"> ；也可以全用 CSS：svg { width: 32px; height: 32px; stroke-width: 2; }（CSS 优先级更高）。

四、颜色继承（currentColor）

stroke="currentColor" 表示“描边用当前文字颜色”， 所以图标继承父元素 color：父级变什么色，图标就变什么色，深色背景也能直接用。

蓝底白字：图标自动变白 （color:#fff → stroke:currentColor）
红色文字：图标自动变红
绿色文字：图标自动变绿
悬停变色（hover 改 color 即可）

五、三种使用方式对比（同一个 heart 图标）

左：JS 把占位符渲染成内联 SVG；中：直接把 SVG 代码手写进 HTML； 右：用 <img> 外链本地 svg 文件。三者外观相同，可控程度不同。

方式 A：data-lucide + JS 渲染（内联 SVG）

颜色 / 粗细随便改，悬停试试

<i data-lucide="heart"></i> + lucide.createIcons()。
DOM 里是真实 <svg> 节点，CSS 可直接改 color / width / stroke-width，可被 JS 操作。

方式 B：手写内联 SVG（无需 JS）

直接写在 HTML 里

把 svg 源码粘进 HTML（源码在 cdn/lucide/svg/*.svg）。
不依赖任何 JS/CSS 文件，同样能用 color / stroke-width 控制，最“纯正”的 SVG 方式。

方式 C：<img> 外链本地 svg 文件

左：原色；右：filter 近似染红

<img src="cdn/lucide/svg/heart.svg">。
写法最简单、可缓存，但 svg 在独立文档里， 父元素的 color 改不动它，只能用 filter 近似染色或换文件。

小结：内联（A/B）可用 CSS 完全控制、能做动画交互；外链（C）省代码但不可样式化； 字体图标（见 13-1）加载快、随文字缩放，但一个字形只能一种颜色、放大会糊（webfont 有分辨率上限）。

六、交互应用

换图标 = 把 data-lucide 换个名字再执行一次 lucide.createIcons()；动态生成也是同理：先插入占位符，再渲染。
