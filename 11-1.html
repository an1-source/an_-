Web 前端长度单位

11-1 · 安家成 · CSS 长度单位演示（绝对单位 / 相对单位）

一、绝对单位（固定大小，不随父元素变化）

换算关系：1in = 96px = 2.54cm = 25.4mm = 72pt = 6pc。 下面六条色条按各自单位设定宽度，除 mm 用 10mm 便于观察外，其余都正好等于 1 英寸。

width: 96px
width: 1cm
width: 10mm
width: 1in
width: 72pt
width: 6pc

二、百分比 %（相对父元素）

父元素固定 400px，子元素用 % 即可按比例自适应，父宽变化时子元素跟着变。

父元素 width: 400px（虚线框）

width: 25% = 100px
width: 50% = 200px
width: 100% = 400px

三、em 与 rem（相对字号单位）

em 相对当前元素自身的字号，层层嵌套会相乘；rem 只相对根元素 html 的字号，永远是同一基准。

父容器 16px：
an_level1：2em = 32px
an_level2：2em = 64px（em 逐层累乘）
拖动滑块修改根字号（html { font-size }），rem 色块会整体缩放： 当前根字号：16px

四、视口单位 vw / vh（相对浏览器窗口）

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。 色条宽度 = 浏览器窗口宽度的百分比，拖动窗口大小试试。

width: 25vw
width: 50vw
width: 100vw
height: 30vh

五、字符单位 ex / ch（相对字体中的字符）

ex 相对小写字母 x 的高度，ch 相对数字 0 的宽度。 下方色块宽 10ex 和 10ch，随字号变化而变化。

字号 20px 的等宽字体示例：0123456789 xxxx
width: 10ex
width: 10ch
