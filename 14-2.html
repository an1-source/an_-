JavaScript 六种基本数据类型

点击每张卡片的"运行示例"按钮，查看对应数据类型的输出结果

String 字符串

用引号包裹的文本，可以用单引号、双引号或反引号。

var an_msg = "Hello World";
var an_name = '安家成';
var an_greet = `你好, ${an_name}`;
（点击按钮查看结果）

Number 数字

整数和浮点数共用 Number 类型，还有特殊值 Infinity、NaN。

var an_int = 42;
var an_float = 3.14;
var an_sqrt = Math.sqrt(-1);  // NaN
var an_divZero = 1 / 0;       // Infinity
（点击按钮查看结果）

Boolean 布尔

只有两个值：true（真）和 false（假），常用于条件判断。

var an_isStudent = true;
var an_isOldEnough = 18 >= 18;   // true
var an_isEmpty = "" === "hello"; // false
（点击按钮查看结果）

Null 空值

表示"故意没有值"的空引用。typeof null 返回 "object" 是历史遗留 Bug。

var an_empty = null;
console.log(an_empty);         // null
console.log(typeof an_empty);  // "object"（历史 Bug）
（点击按钮查看结果）

Undefined 未定义

声明了变量但未赋值时的默认值；访问不存在的属性也会得到 undefined。

var an_x;
var an_obj = { a: 1 };
console.log(an_x);           // undefined
console.log(an_obj.b);       // undefined
（点击按钮查看结果）

Symbol 符号 (ES6)

一种唯一且不可变的值，常用于对象的"私有"属性键。

var an_sym1 = Symbol("id");
var an_sym2 = Symbol("id");
console.log(an_sym1 === an_sym2); // false
console.log(typeof an_sym1);       // "symbol"
