四句话记住对象

{ key: value }

对象是"键值对"的无序集合，键一定是字符串（或 Symbol），值可以是任意类型。

obj[key]

点号取值要求键名合法；方括号能接变量，obj["my key"] 这种带空格的键必须用方括号。

this

方法里的 this 由"谁调用"决定，不由"写在哪"决定；箭头函数没有自己的 this。

引用

b = a 只是复制门牌号，两人住同一间房；{ ...a } 才是新盖一间房。
