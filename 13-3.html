实现说明

四个图标来自 picture/ 目录（主页.svg / 发现.svg / 消息.svg / _我的.svg）。 由于这些 svg 文件里的 fill 颜色是写死的（紫色、灰色……）， 用 <img> 引入后无法改色；这里改用 CSS mask（遮罩）： svg 只当“形状模板”，再用 background-color: currentColor 上色， 于是图标颜色就能跟随选中态 / 文字颜色变化（延续 13-2 的 currentColor 思路）。 

/* 图标本体：svg 只提供形状，颜色由 background-color 决定 */
.an_icon {
    width: 26px; height: 26px;
    background-color: currentColor;               /* 跟随文字颜色 */
    -webkit-mask: url("picture/主页.svg") no-repeat center / contain;
            mask: url("picture/主页.svg") no-repeat center / contain;
}
/* 选中态：胶囊底色 + 图标/文字变绿（颜色全靠 currentColor 继承） */
.an_tab-active           { color: #0F8F63; }
.an_tab-active .an_icon-box { background: #DDF3E8; }   /* 浅绿胶囊 */

其他细节：border-radius: 999px 做胶囊选中态；角标用绝对定位叠在图标右上角， 点击时 stopPropagation() 避免触发 tab 切换；导航卡片外预留 env(safe-area-inset-bottom)，在全面屏 iPhone 上不被 Home Indicator 遮挡； 最底部的黑色横条即 iOS 的 Home Indicator。

图标文件：picture/主页.svg、发现.svg、消息.svg、_我的.svg（iconfont 风格，viewBox 1024×1024）
